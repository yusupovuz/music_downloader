# MusicDownload Service

Асинхронный сервис для поиска и скачивания музыки, реализованный в рамках тестового задания.

## Особенности архитектуры
- **Асинхронность:** Использование `asyncio` и `aiohttp` для неблокирующих запросов.
- **Многопроцессность:** Скачивание аудио через `yt-dlp` вынесено в отдельный процесс (`multiprocessing`), что предотвращает блокировку основного потока.
- **Строгая типизация:** Валидация и форматирование данных через `Pydantic` Dataclasses.
- **Обход блокировок:** Текстовый поиск интегрирован напрямую с Apple/iTunes API (бэкенд Shazam) из-за отключения текстовых эндпоинтов Shazam (Amazon S3 NoSuchKey Error) и защиты Cloudflare.
